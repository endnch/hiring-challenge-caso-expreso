# Cómo correrlo

Requisitos:
- Python 3.9 o posterior (probado con 3.14).
- SQLite 3.37 o posterior, la que trae Python (`python -c "import sqlite3; print(sqlite3.sqlite_version)"`).
  Los instaladores de python.org la incluyen; algunas distribuciones de Linux traen una más vieja
  (Ubuntu 20.04, Debian 11).
- Dependencias: `pip install -r requirements.txt`
